# WorldWise

Apprendre les drapeaux, les capitales et la carte des pays du monde, et
s'entraîner pour GeoGuessr (langues et écritures, repères des panneaux de direction).

## Photos des repères de panneaux

Base fixe : photos de rue de Mapillary (licence CC BY-SA 4.0, auteur cité sous
chaque photo), choisies et recadrées une fois pour toutes, dans `photos/` ;
`photos.js` les liste par pays.

## Lancer en local

Double-cliquer sur `lancer.bat`, ou servir le dossier avec n'importe quel serveur statique :

    python3 -m http.server 8080
